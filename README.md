# Etch-a-Sketch Web App
**[Live Demo](https://bjtn1.github.io/etch-a-sketch/)** | [GitHub Repo](https://github.com/bjtn1/etch-a-sketch)

A browser-based drawing application built with vanilla JavaScript.

## Features
- Dynamic grid resizing (1×1 to 100×100)
- Real-time color selection
- Drawing and erasing functionality
- Instant grid clearing
- Responsive Flexbox layout

## Installation
1. Clone the repository:
```bash
git clone https://github.com/bjtn1/etch-a-sketch.git
```

2. Open `index.html`

## Technologies
- Vanilla JavaScript
- CSS3 (Flexbox, transitions)
- HTML5
